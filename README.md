# Vampire 20th Character Forge

A free, local-first character builder for **Vampire: The Masquerade 20th Anniversary Edition**.

Templates: Vampire, Ghoul, Revenant, and mortal NPC. The guided forge includes Camarilla/Anarch, Sabbat, and independent terminology sets. `advanced.html` opens the original specialist Vampire workspace for clan auto-fill, blood magic paths and rituals, and Generation limits inside the shared Character Forge branding.

This forge shares an engraved-sigil design system, book-page workspace, controls, and print treatment with the Mage, Werewolf, Wraith, and Changeling forges while retaining a Vampire-specific blood-and-fang seal and palette.

Open `index.html` in a browser. No account, server, analytics, or network connection is required.
