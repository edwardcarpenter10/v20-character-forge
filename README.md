# Vampire 20th Character Forge

A free, local-first character builder for **Vampire: The Masquerade 20th Anniversary Edition**.

Templates: Vampire, Ghoul, Revenant, and mortal NPC. `advanced.html` preserves the original specialist Vampire workspace for clan auto-fill, blood magic paths and rituals, Sect terminology, and Generation limits.

Open `index.html` in a browser. No account, server, analytics, or network connection is required.
